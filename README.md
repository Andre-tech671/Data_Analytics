# Data Analytics Repository

This repository contains my data analytics projects, case studies, and scripts.  
It showcases work in exploratory data analysis (EDA), visualization, and applied machine learning.

## Contents
- **Exploratory Data Analysis (EDA):** Jupyter notebooks analyzing datasets.
- **Visualization Projects:** Dashboards and plots using Python libraries (Matplotlib, Seaborn, Plotly).
- **Machine Learning Applications:** Predictive modeling and classification tasks.
- **Case Studies:** Real-world data problems with socio-economic and policy relevance.

## Tools & Technologies
- Python (Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Plotly)
- SQL
- Jupyter Notebooks
- Git & GitHub
